Map spike: the 1941 map in four projections

The built 1941 board (worlds/maps/autumn-1941.json, 360 degrees wide) drawn four ways, each at the whole map and at two region frames. The three proper projections are centred on the map's middle longitude; the first column is what the game draws today. Lines every 30 degrees of longitude and 15 of latitude show the shape of each projection. The dashed boxes on the whole map are the two region frames below it.

Opens from the file system with no server. The timing bench is the same page with ?bench=viewbox, ?bench=transform or ?bench=canvas; see RESULTS.md for the numbers and the command that made them.
